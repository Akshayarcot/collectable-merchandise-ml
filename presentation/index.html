1. Problem Statement & Motivation

Primary vs. Secondary Market Reality

• Manufacturers set fixed retail pricing ($10 - $15) across items.

• In secondary marketplaces (StockX, eBay), resale prices diverge wildly ($14 to $2,150+).

• Valuations are driven by intangible fandom demand, convention releases, and production scarcity.

Machine Learning Challenges

• Severe Transaction Scarcity: High-tier grails have very few historical sales.

• Extreme Lognormal Skew: Direct continuous regression produces massive variance.

• Mixed Heterogeneous Data: Continuous search interest + discrete categorical attributes.

• Task Formulation: Imbalanced multi-class classification into 5 log-spaced price bins.

2. Dataset Details & Feature Pipeline

Dataset Composition (358 Curated Items)

• Anime: 198 items (55.3%)

• Marvel: 69 items (19.3%)

• Ad-Icons: 43 items (12.0%)

• Disney: 37 items (10.3%)

• Game-of-Thrones: 11 items (3.1%)

Price Intervals (Log-Spaced Bins)

• Bin 1: [$14.00, $38.13] — 146 items (Common Retail)

• Bin 2: ($38.13, $104.87] — 153 items (Modest Premium)

• Bin 3: ($104.87, $287.02] — 46 items (Con Exclusive)

• Bin 4: ($287.02, $785.55] — 10 items (Grail Status)

• Bin 5: ($785.55, $2150.00] — 3 items (Ultra Grail)

Feature Engineering: Continuous Search Volume normalized via log(1 + x) and Min-Max scaling to [0, 1]. Categorical attributes encoded via One-Hot Encoding (baselines) & Ordinal Encoding with marginal distribution P(Z=z) (custom kernel).

3. Technical Methodology

1. Baseline Linear SVM (One-vs-One)

• Evaluates linear separability in one-hot feature space.

• OvO pairwise binarization limits the impact of majority class dominance.

2. Vanilla Decision Tree (CART)

• Greedy non-parametric recursive splitting using Gini impurity.

3. Proposed Custom Kernel SVM

• Standard RBF fails on categorical data; linear fails on complex curves.

K(i, j) = w₁·U₁(xᵢ, xⱼ) + w₂·U₂(zᵢ, zⱼ) + w₃·U₃(zᵢ, zⱼ) + w₄·U₄(zᵢ, zⱼ)

U₁(xᵢ, xⱼ) = exp( - (xᵢ - xⱼ)² / 2θ² ) [Gaussian RBF]
Uₖ(zᵢ, zⱼ) = (1 - P(zᵢ)^α)^(1/α) · 1{zᵢ == zⱼ} [Marco Overlap]
Domain Weights: w = [2, 1, 1, 3] (Search Vol, Cat, Mat, Special Ver)

• Bagged Decision Tree: Ensemble of 10-200 trees via bootstrap sampling to slash variance.

6. Conclusions & Future Directions

Conclusions

• Custom Kernel Efficacy: Incorporating domain weights and probability-adjusted categorical similarity allows SVMs to capture rare, high-value collectibles.

• Ensemble Variance Reduction: Bagging eliminates the severe overfitting of single trees, achieving 0.673 test precision.

• Industry Application: Enables automated appraisal and bid-ask recommendations on secondary marketplaces.

Future Scope

• NLP Fandom Sentiment: Fine-tune LLMs/BERT on collector communities (Reddit r/funkopop) to detect emerging demand before transaction data emerges.

• Computer Vision Packaging Analysis: Integrate CNNs to inspect box corners, window creases, and authentication holograms to adjust valuations for condition grading.
